A few Home Assistant components I maintain (or try to):
- [ha-gtfs-rt](https://github.com/zacs/ha-gtfs-rt): Real-time transit information.
- [ha-dualmodegeneric](https://github.com/zacs/ha-dualmodegeneric): Generic thermostat that can both heat and cool.
- [ha-receipt_printer](https://github.com/zacs/ha-receipt_printer): Epson receipt printer component.
- [ha-nfl](https://github.com/zacs/ha-nfl): NFL game scores.
- [hass-wattbox](https://github.com/eseglem/hass-wattbox): WattBox power distribution component.
- [rtl_433_ha_autodiscovery](https://github.com/zacs/rtl_433_ha_autodiscovery): Isolated autodiscovery container that brings RTL_433 devices from MQTT into Home Assistant.
- [ha-mattermost](https://github.com/zacs/ha-mattermost): Mattermost notification component.
- [ha-voipshim](https://github.com/zacs/ha-voipshim): Shim that lets a standard SIP server connect to the Home Assistant VoIP integration.
- [ha-energycalc](https://github.com/zacs/ha-energycalc): Adds energy (kWh) sensors to devices that only report power (W).
- [tunnel-monitor](https://github.com/zacs/tunnel-monitor): Monitors and updates Tailscale, IPsec, and Unifi Site Magic tunnels via Home Assistant.
- [ha-clean_energy](https://github.com/zacs/ha-clean_energy): Detects large energy spikes and offers "clean" sensors with the spikes removed.
- [ha-noaa_weather_radio](https://github.com/zacs/ha-noaa_weather_radio): Sends NOAA weather alerts from an RTL-SDR into Home Assistant.
- [ha-polycom_speakerphone](https://github.com/zacs/ha-polycom_speakerphone): Monitors Polycom Trio 8800 SIP speakerphones.
- [homebrew-ha-apple_content_cache-client](https://github.com/zacs/homebrew-ha-apple_content_cache-client): Homebrew-installable client that pushes Apple content caching metrics to Home Assistant.
- [nfs-ha-monitor](https://github.com/zacs/nfs-ha-monitor): Monitors an NFS connection and reports its status to Home Assistant.
